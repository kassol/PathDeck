# S25：i18n 多语言支持

> 日期：2026-06-17
> 前置：S24 已合入

## 目标

建立本地化基建，提取全量硬编码字符串，支持 en + zh-Hans 双语，跟随系统语言自动切换。

## Scope

| # | 内容 | 涉及文件 |

| 1 | 创建 String Catalog（`Localizable.xcstrings`） | 新建 `Localizable.xcstrings` |
| 2 | 菜单栏字符串本地化 | `PathDeckApp.swift` |
| 3 | 右键菜单字符串本地化 | `FileTableView.swift` |

## Not Building

- 日语 / 韩语 / 其他语言（后续按需加，String Catalog 加语言成本极低）
- 日期 / 数字 / 文件大小格式化（已用系统 formatter，天然跟随 locale）
- Info.plist 本地化（App 名称保持 "PathDeck" 不翻译）

---

## 关键决策

| 决策 | 选择 | 理由 |
|------|------|------|
| 基语言 | en | 国际化标准；中文作为翻译目标语言 |
| 首批语言 | en + zh-Hans | 覆盖作者和目标用户的主要语言 |
| 本地化方案 | Xcode String Catalog（`.xcstrings`） | Xcode 15+ 原生，编辑友好，自动提取，无需手写 key |
| 列头标题 | 跟随系统语言 | Name/Date Modified/Size/Kind ↔ 名称/修改日期/大小/类型 |
| SwiftUI 字符串 | `String(localized:)` + literal `LocalizedStringKey` | SwiftUI `Text("literal")` 自动走 localized lookup；AppKit 用 `String(localized:)` |
| AppKit NSMenu 字符串 | `String(localized:)` | NSMenu title 不自动走 localization，需显式调用 |

## 实现模式

### SwiftUI（Text / Button / Menu / Label / .help）

SwiftUI 的 `Text("literal")` 和 `Button("literal")` 自动将字面量作为 `LocalizedStringKey` lookup。**无需改代码**，只需确保 String Catalog 中有对应 entry。

含插值的需用 `String(localized:)` 包裹：

```swift
// Before
Text("\(count) items selected")

// After
Text(String(localized: "\(count) items selected"))
```

### AppKit（NSMenu / NSAlert）

NSMenu / NSAlert 的 title 是普通 `String`，不走自动 lookup，需显式：

```swift
// Before
addMenuItem(to: menu, title: "新建文件夹", ...)

// After
addMenuItem(to: menu, title: String(localized: "New Folder"), ...)
```

### NSTableColumn

```swift
// Before
("名称", 280, 120)

// After
(String(localized: "Name"), 280, 120)
```
